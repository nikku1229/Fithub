1. INSTALLATION FOR THE ROUTER 

   npm install expo-router

This give a architecture and layout of the codebase as per the router base that native identifies itself by folder pages.


2. INSTALLATION FOR THE GLOBAL STATE MANAGEMENT

   npm install zustand axios expo-secure-store

This install dependence of the zustand and integration of server to client pipeline

Then config environment varible in .env as per .env.example


3. VALIDATION OF INPUT DATA

   npm install zod

This dependency is used to validate every input field or data before hitting the API.
